# the-c128-keyboard-project
This project contains everything needed to build a replacement keyboard for any model of the C128.  It mounts using the stock hardware in the flat, D, and DCR models.

This work is very intentionally licensed for commercial use in the hope that someone will produce and sell these boards in kit and/or assembled form.  See [LICENSE.md](LICENSE.md) for more details.
