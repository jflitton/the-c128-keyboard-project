# PCB Plate

This is a clone of the step plate. In October 2026 I had 5 plates made by JLCPCB in aluminum with a black top.
The plates work well for the mid-low switch setup using adapters and the original keycaps.

The 9u spacebar does not align with the standard layout of an MX 9u spacebar. It works with the adapters and
Mitsumi spacebar. Because of this issue there are now 3 different plates.

Latest version puts all switch openings at 14mm, standard for MX/Mitsumi.

# Plates
6.25U-MX: MX Plate for 6.25u spacebar.
9U-MX: MX Plate for 9u spacebar, MX spacing as defined by Singature Platics spacebar. Requires clip-in stabs for the spacebar.
9U-Mitsumi: Clone of original step plate for Mitsumi keyboard with adapters to fit MX switches/stabs.
